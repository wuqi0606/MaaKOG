# MaaKOG

基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 构建，免费开源。

## 开始使用

1. 到 [Releases](https://github.com/wuqi0606/MaaKOG/releases) 下载最新版本的压缩包。
2. 解压后，**先以管理员身份运行 `DependencySetup_依赖库安装_win.bat`**（Windows），自动安装 VC++ 和 .NET 运行库。
3. 运行 `MFAAvalonia.exe`。

**运行环境**

- Windows / macOS / Linux 电脑
- 安卓模拟器（推荐 MuMu），模拟器需要开启 ADB 调试

**Python 环境**

- **Windows（win-x86_64 包）**：已内置 Python 3.13.17 和 maafw 5.16.1，**无需任何安装**，解压即用。
- **macOS / Linux / 其他平台**：需自行安装 Python 3.10+（[下载](https://www.python.org/downloads/)），agent 启动时会自动检测并安装 maafw 5.16.1。

如自动安装失败（网络/权限问题），手动执行：

```bash
pip install maafw==5.16.1
```
